# Software Development Portfolio

Portfólio pessoal desenvolvido para apresentar projetos, trabalhos e canais de contato de Carolina Maini.

## Sobre o projeto

Este repositório contém a implementação de um site estático de portfólio, com seções dedicadas à apresentação profissional, exposição de projetos e contato.

## Funcionalidades

- Seção de apresentação pessoal.
- Galeria de projetos com carrossel de imagens.
- Navegação por âncoras entre as seções.
- Área de contato com links para canais profissionais e redes sociais.
- Ícones e recursos visuais para complementar a interface.

## Tecnologias

- HTML5
- CSS3
- Bootstrap 5
- Bootstrap Icons
- JavaScript utilizado pelos componentes interativos do Bootstrap

## Estrutura do projeto

| Arquivo / diretório | Finalidade |
| --- | --- |
| `index.html` | Estrutura e conteúdo das seções do portfólio |
| `style.css` | Estilos e identidade visual |
| `reset.css` | Normalização de estilos |
| `*.png`, `*.ico` | Imagens dos projetos, imagem de perfil e ícones do site |
| `site.webmanifest` | Metadados para instalação/identificação do site |

## Executar localmente

1. Clone este repositório.
2. Abra o arquivo `index.html` no navegador.

Não é necessário configurar servidor ou instalar dependências para visualizar a versão estática.

## Objetivo

Centralizar a apresentação de projetos e experiências em desenvolvimento web, facilitando a navegação por trabalhos selecionados e o contato profissional.
